# Results

Generated evidence. Every headline number in the project README comes from a
file in this directory, and each was produced by the command named below.

| File | Produced by |
| --- | --- |
| `metrics.json`, `metrics_table.md` | `python scripts/collect_metrics.py` |
| `aws_audit_results.json` / `.csv`, `aws_audit_tickets.txt` | `python -m lab.run_benchmark` (primary lab profile) |
| `aws_audit_results_no-trail.json` | `python -m lab.run_benchmark` (`no-trail` profile) |
| `expected_vs_actual.json`, `benchmark_report.md` | `python -m lab.run_benchmark` |
| `fixture_manifest.json` | `pytest tests/test_fixture_manifest.py` |
| `coverage.json` | `pytest --cov=auditor --cov-report=json:results/coverage.json` (gitignored: large, and regenerated by every run) |

The audit reports come from the deliberately misconfigured **emulated** test
account described in [`../docs/test-environment.md`](../docs/test-environment.md),
not from a live AWS account — the reports say so in their own
`metadata.environment` field. Access key IDs are masked, because these files are
committed; redaction runs after detection and changes nothing that was found.
