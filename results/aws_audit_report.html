The bucket policy on 'lab-blocked-public-policy' contains an Allow statement with an anonymous principal. Public access is currently blocked by the bucket's Public Access Block settings, but the statement remains in the policy and takes effect if those settings are removed.

Why it matters. An anonymous Allow in the resource policy grants access without any authentication, independently of IAM. Conditions can narrow it, but they have to be read: an aws:SourceIp condition constrains access while an aws:SecureTransport condition does not.
